# 🎮 Pixel Dash

Pixel Dash is a fast-paced 2D endless runner game developed in **Unity** using **C#**. The player controls a character that continuously runs forward, avoiding obstacles, collecting coins, and aiming for the highest possible score.

---

## 📌 Features

- 🏃 Smooth player movement
- ⬆️ Jump mechanics
- 🚧 Dynamic obstacles
- 🪙 Coin collection system
- 📈 Score tracking
- ❤️ Lives/Health system (if implemented)
- 🔊 Sound effects
- 🎨 Simple and engaging 2D graphics
- ⚡ Optimized collision detection
- 🎯 Endless gameplay

---

## 🛠️ Built With

- **Unity**
- **C#**
- Unity Physics 2D
- Unity UI System
- Visual Studio

---

## 🎮 Gameplay

The objective is simple:

- Avoid obstacles.
- Collect coins to increase your score.
- Survive as long as possible.
- Beat your highest score.

As the game progresses, the difficulty increases, making it more challenging and exciting.
